# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.
Users can browse houseplants by category, add them to the cart, change quantities,
remove items and see the total cost.

## Features
- Landing page with a Get Started button
- Three plant categories with six plants each
- Add to Cart button that disables after adding
- Live cart count in the navbar
- Cart page with quantity controls, delete, total cost and checkout message
